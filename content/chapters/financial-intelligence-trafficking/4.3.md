Implementation Roadmap: 90-Day Playbook (Audit-Ready) Objective: Give MLROs a time-boxed plan to go live quickly while meeting audit/regulatory expectations. Phase 1 (Days 0–30): Baseline & Policy Lift • Approve HT Policy & Standards; update EWRA methodology. • Create HT Red Flag Matrix and publish HTRAF rule catalogue. • Identify high-risk customer cohorts; queue for EDD refresh. • Enable case taxonomy in the case manager (“Human Trafficking / Exploitation”). • Launch awareness training (20–30 min) for front line; publish branch/ops checklist. Phase 2 (Days 31–60): Controls & Data • Deploy initial TM/KYT rules; set review SLAs; define “investigation notes” template. • Integrate blockchain analytics (for VASPs/crypto exposure); pilot on corridors. • Stand up PPP touchpoint (FIU liaison, NGO intel, banking association working group). • Build Board dashboard; align KRIs/KPIs; test STR narrative scaffold with real cases. Phase 3 (Days 61–90): Optimize & Evidence • Calibrate thresholds using back-testing; tune for precision/recall. • Run table-top exercise: end-to-end case → STR → FIU feedback. • Internal Audit “readiness review”: evidence pack (policies, EWRAs, training logs, alert samples, STRs, PPP minutes).
